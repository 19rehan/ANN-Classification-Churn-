# 🧠 ANN Customer Churn Prediction

## 📌 Overview
This project uses an **Artificial Neural Network (ANN)** to predict **customer churn** — whether a customer is likely to leave a service. Customer churn prediction is a critical business problem, as retaining existing customers is often more cost-effective than acquiring new ones.  

The model is built using **TensorFlow/Keras** and demonstrates the end-to-end workflow of:
- Data preprocessing
- Feature scaling
- ANN architecture design
- Model training & evaluation
- Performance visualization



- 

---

## 🚀 Features
- **Data Preprocessing**: Handling categorical variables, missing values, and feature scaling.  
- **ANN Model**: Multi-layer perceptron with ReLU activations and sigmoid output.  
- **Evaluation Metrics**: Accuracy, confusion matrix, precision, recall, F1-score.  
- **Visualization**: Training/validation loss and accuracy plots.  
- **Deployment Ready**: Model can be saved and loaded for inference.

## ⚙️ Model Architecture
- **Input Layer**: Features after preprocessing  
- **Hidden Layers**: Dense layers with ReLU activation + Dropout for regularization  
- **Output Layer**: Single neuron with Sigmoid activation (binary classification)

## 📊 Results
- **Accuracy**: ~85% (depending on dataset & tuning)  
- **Confusion Matrix**: Shows correct vs. incorrect predictions  
- **Precision/Recall/F1**: Balanced evaluation for churn prediction
